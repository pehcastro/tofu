# bench startup, shell resolution and the toolchain probe before the first token: 2026-09-23

Machine: DESKTOP-AHUN9RO. No live model call, no network call: every figure is `internal/turn.NewBashTool` timed directly, over 6 rounds.

`go test ./bench/startup/... -count=1` passes, 3 test functions.

## Threshold, chosen before the measurement

**100 ms.** 100 ms is Nielsen's own boundary for a response that feels instant rather than a wait. Below it there is nothing worth overlapping with the first model call; above it the delay is worth hiding behind one.

## Method

`NewBashTool` resolves the shell and probes the toolchain in one call, with no exported seam between the two, so the toolchain probe cost is derived rather than timed directly. Each round times `NewBashTool` on an empty temporary directory carrying no `go.mod`, `package.json` or `pyproject.toml`, which measures shell resolution alone because `projectInterpreters` finds nothing to probe there, immediately followed by `NewBashTool` on the project directory. The probe cost is the difference between the two calls made back to back; a project total at or below its adjacent baseline is floored to zero rather than reported negative.

Shell resolution: median 101.5 ms, worst 135.3 ms, over 12 samples, crosses it.
