# Skills, with and without, 2026-09-26

TOFU-734. The question was whether skills earn a place in tofu. He decided that library content speaks through rules, references and guidance, and that skills get tested as an experiment only.

## Verdict

Skills earn a narrow place and no wider one.
- With the listing on, the model loaded the right skill in 2 of 3 tasks and followed it both times.
- On the third task (the file header) it never called `skill` and ignored the convention without saying so.
- With the listing off, 0 of 3 followed the convention, as expected.
- The listing and the tool cost 247 cached tokens per request: 7,762 against 7,515.

Keep the loader for a person's own skills. Do not move library content into skills: a convention meant to always apply was skipped once in three, silently. There was one run per cell, so this shows what can happen, not a rate.

## The runs

Six live runs on `claude-sub/claude-sonnet-5 --effort low`, through the subscription wire with `--no-gate --sift free --no-subagents`. Each ran in a fresh project copy and a fresh home that held only a copy of the claude-sub credential.

| task | skills | `skill` called | output followed the skill |
| --- | --- | --- | --- |
| write a commit message | on | yes (commit-style) | yes |
| write a commit message | off | no listing | no |
| create a source file | on | no | no |
| create a source file | off | no listing | no |
| write a test | on | yes (test-names, plus file-header) | yes, both |
| write a test | off | no listing | no |

The per-run token totals were not recorded. The only token figure measured is the listing's cost per request, given above.

## The skills

Three throwaway skills in the scratch project, one in each discovery folder. Each has a convention the output can be checked against:
- `commit-style` in `.tofu/skills`: the commit message format.
- `file-header` in `.agents/skills`: the header every new source file starts with.
- `test-names` in `.claude/skills`: how tests are named.

## How the loader works

The loader copies oh-my-pi's shape.
- **Discovery.** It reads `.tofu`, `.agents` and `.claude` skill folders from the working folder up to the repository root, then the same three under the home. The first name wins. It deduplicates by real path and warns on a collision (omp `extensibility/skills.ts`, `discovery/builtin.ts`, `claude.ts`).
- **Listing.** It follows codex's budget: 1,024 characters per description, and 2% of the window for the whole list, or 8,000 characters when the window is unknown. Descriptions are dropped before names (codex `ext/skills/src/render.rs`).
- **Loading.** A `skill` tool loads a body by name, and refuses a path outside the skill's folder (omp `internal-urls/skill-protocol.ts`).
- **Setting.** `skills off` removes the listing.
