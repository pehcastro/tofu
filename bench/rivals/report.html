Method, parity and conditions

Method

itemwhat it is
taskone small Go package, testdata/seed, and one prompt, testdata/prompt.txt: a bug, a feature, a rename, a question and a new file
qualityhidden tests from testdata/hidden plus the rubric in score.go: visible tests, gofmt, go vet, the old name gone, no stray files
verdicta win or a loss only when the lowest to highest spreads of the two arms do not meet; otherwise a tie
orderone run at a time behind the rival slot, on the owner's subscriptions, no money
networkthis bench needs the network and spends subscription quota; the report itself reads only runs/
rerungo run ./bench/rivals run -arm <arm> -rep <n> -setting omitted -batch <batch> -slot <dir>, then go run ./bench/rivals report -batch <batch>

Parity

Read off the rival's own stdout or rollout of the first run of each arm; the models and the thinking tofu sent are in the conditions table.
