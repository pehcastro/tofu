## What had to change in the harness before this could run

Four defects were fixed earlier today: staging between repeats, tofu's thinking effort, the tofu arm's cache-blind token count, and the offline default. Three more were found and fixed while setting this run up.

**The runner refused to execute the claude and codex arms at all.** It printed their plans and stopped. That is now behind a `--spend` flag, so the refusal is still the default.

**Staging left no git repository behind, so every gate that reads a diff could not evaluate.** Staging deletes the arm directory and copies the seed in, which took `.git` with it, so both the test-count gate and the diff-cost gate returned could_not_evaluate. **Every row would have failed the gate door for a harness reason.** Staging now makes a seed commit, and the diff-cost figures above exist because of it.

**The tofu arm was being handed this repository's own CLAUDE.md.** `tofu run` walks up from its working directory for `AGENTS.md` and `CLAUDE.md` and injects what it finds as instructions that outrank the task. **This project's begins "You are the orchestrator. You do not write code."** The claude arm was already immune because the plan passes `--safe-mode`. Codex was immune by accident: there is no `AGENTS.md` above it. Staging now writes an empty `AGENTS.md` and `CLAUDE.md` into the arm directory.

**The claude and codex arms ran before that last fix and their trees did not have those two files.** For claude this is inert, because `--safe-mode` had already turned CLAUDE.md off. For codex it is inert because there was nothing above it to find. **Only the tofu arm was materially affected, and it ran after the fix.** The three trees are therefore not byte-identical: tofu's carries two empty files the other two did not. Stated rather than hidden, and the next run will have all three alike.
