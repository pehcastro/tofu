# bench search: 2026-09-23

Machine: DESKTOP-AHUN9RO, Windows 10 Pro 19045, go1.27.1 windows/amd64. No model was called and no network was used. The tree measured was the tracked working tree, 1513 files, with dot directories and `rtk` skipped.

## ANSWER

**The plan's claim that four search patterns cost nothing is false as written, and the rescue rate on recorded searches is zero.**

`.local/boji/planning/doing/tool-calls.md:152` says code can run four candidate patterns for the price of nothing. Run over the whole tree they cost 320 ms against 14 ms for the literal. The first implementation did exactly that and spent 638 ms of candidate scan on an 819 ms call.

**What the candidates are worth is not rescuing a wrong pattern. It is telling an absence from a mistake.** Six of twenty replayed searches returned nothing, and not one of the six was a case error.

## The numbers

Each form runs only where it can change the answer. The word boundary and Go symbol forms match a subset of the literal, so they are provably empty when the literal misses and need only its matches when it hits. Case folding is the only form that can widen.

Cost over the real tree, 5 runs each, median:

| pattern | whole call | reading files | literal | other forms |
|---|---|---|---|---|
| a two branch regexp | 554.8 ms | 139.5 ms | 413.8 ms | not run |
| a plain word that hits | 164.9 ms | 131.5 ms | 15.6 ms | word boundary 4.8 ms, go symbol 6.3 ms |
| a word that misses on case | 591.7 ms | 270.1 ms, twice | 11.7 ms | case insensitive 303.6 ms, answered |
| a word that is absent | 599.3 ms | 270.9 ms, twice | 14.2 ms | case insensitive 316.9 ms, answered by none |

**The narrowing forms are free**: 11 ms of a 165 ms call, against 131 ms spent reading files. A test fails if they ever exceed the read.

**Telling an absence from a wrong pattern is not free**: about 590 ms against about 150 ms for a bare empty search, roughly 3.5x. 320 ms of that is the case folding regexp, which cannot use the literal prefilter, and 135 ms is the second read pass.

## The corpus

23 recorded `search` tool calls read out of `.tofu/sessions` at run time, zero written by hand, every row carrying the id of the turn it came from. 20 replayed, 3 skipped because the recorded path is gone from the tree.


**The rescue rate is 0 of 6.** What this buys on his corpus is the other half: **6 of 20, 30 percent, of real searches now say absence instead of being ambiguous.** On this evidence, nothing more should be spent on the widening form.

## Leakage, and the failure it caught

Three checks run before the measurement: self answer, identity and credential scan, and provenance. All three pass at zero.

**The self answer check caught four real leaks across two rounds before reaching zero, and the mechanism is worth stating.** The corpus is replayed over the whole tree, and this bench lives in that tree. The first cost test named two recorded patterns as string literals, and replaying one of them flipped from absent to found **because the bench's own test file answered it**: the headline went 6, then 4, then back to 6 once it was removed. The first draft of the provenance file then quoted the patterns in prose and the check caught it again.

Nothing in this directory now contains a whole recorded pattern. The cost measurement draws its patterns from the corpus at run time or composes them from pieces.

## What this cannot answer

- **Whether a case error is rare or absent.** Zero of six on twenty searches is one machine's history, not a rate.
- **Whether the wall clock holds.** The tree grew from 1510 to 1513 files during the measurement, because other agents were writing. The per form comparisons are within a single run and hold; the absolute milliseconds are against a moving tree.
- **Whether the replay reflects the searches as recorded.** It runs against today's tree, not the tree each search was recorded against. Two package paths and four rows the loader looks for are gone, and that drift is most of the six absences.
- **Anything about the judged half.** Choosing among result sets has its inputs sitting ready, and it has no measurement behind it, so it is not wired.
