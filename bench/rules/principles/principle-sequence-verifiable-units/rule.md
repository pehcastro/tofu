Rule: break multi-part work into small units, each ending in a state you can check, and do not start the next until the current one is green. Start from a green baseline: run the existing tests first. Then make one change, run the check, and only then move on. Write the failing test for a unit before its fix. A break found at the unit that caused it is cheap; a break found after a batch is buried under everything built on top of it.
