Rule: encode the domain in a data structure instead of scattering it across conditionals. Replace a set of booleans that must stay in sync with one state type and an explicit table of allowed transitions; replace an if/else chain that grows by a branch per case with a lookup table or a type per case. Make invalid states impossible to represent, and reject a transition the domain does not allow. Keep plain code when the current shape is already clear and will not grow.
