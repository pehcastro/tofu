Rule: when a change is not trivial, build the tool that makes it instead of editing by hand. Do the first site by hand to learn the recipe, then write a small program that applies it to every site, rerun it and diff the result against your hand edit. A codemod, a script or a generator is the artifact a reviewer can rerun; hand edits can only be checked by redoing them. Skip the tool only for a couple of edits you can see at a glance.
