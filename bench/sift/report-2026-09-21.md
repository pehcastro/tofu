## The check that catches the next omission

`bench/report/corpus_test.go:TestEveryBenchCorpusHasADatedReport` walks every package under `bench/`. Any package whose `testdata` holds a file that is not `PROVENANCE.md` and whose own directory carries no `report-YYYY-MM-DD.md` fails it. It is gated behind `TOFU_SWEEP_CORPUS_REPORTS=1` and skipped otherwise, because it is tree-wide and would fail this package's own `go test ./bench/... -count=1` on packages outside this ticket's `owns` while their tickets are mid-flight.
