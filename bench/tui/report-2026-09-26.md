# Interface benchmarks against the showcase baseline, 2026-09-26

Taken once at `5fbabc5`, before TOFU-718 and TOFU-719. The baseline is `.local/boji/planning/doing/tui-port/showcase-baseline.md`.

## Outside the 16.7 ms budget, named first

- **ResizeFrame, every screen: 97 to 169 ms a frame.** A resize re-renders the whole chat transcript through glamour, whatever screen is shown. `interface/tui/session.(*Model).SetSize` calls `rerender`, which calls `markdown.(*Renderer).Lines` for every entry: 93% of the resize CPU. The showcase never measured a resize.
- **FirstOpenRender/sub-agents: 59.6 ms for the first frame.** `interface/tui/feed.Model.cardsFor` renders every card, not only the visible ones. Single sample. The frames after it take 0.80 ms.
- **SessionViewLongTranscriptAtTheTail 36.3 ms, SessionViewLongTranscriptScrolledBack 21.9 ms.** Older synthetic benches: 10,000 running tool calls with tool detail on. Not a showcase row.

Every progressed render is inside the budget. The slowest is file edits: 2.47 ms on the recent session and 2.37 ms on the long one.

## Conditions

- Windows 10 Pro 19045, Intel i9-14900K, go1.27.1, the baseline's machine. Commit `5fbabc5`, 2026-09-26 06:02 to 06:06, one run of 226.9 s, other agents working.
- `GOMAXPROCS=4 go test ./bench/tui/... -run '^$' -bench . -benchtime=300ms -count=1 -benchmem -p 1`. No network, no credential, no model call.
- Every screen row is 120x36 on the real `tui.App` from `tui.New`, every setting at its default.
- The replay reads `.tofu/sessions` through `internal/session.Store`. No recorded session has 30 turns, so the replay is the 30 most recent top-level turns in recorded order as one sitting, `turn-18d734967b349e38` to `turn-18d87bfa62c7d64c`. It has three spawn turns with six children. Its largest edit is 267 lines, under the 300 asked. Its one shell comes from `<projects>/admin-template/.tofu/shells`, because session records hold no background shells.
- Screens are reached by tab, settings by its link, and file edits opens the largest edit with `n`.

## After TOFU-719

Run once by the orchestrator after TOFU-718 and TOFU-719, same command and machine, 44.1 s. The replay went from 227 s to 44 s because a tool result no longer pays for a lexer lookup.

Every row is now inside the 16.7 ms budget.

- ResizeFrame: chat 1.91 ms, sub-agents 1.63, file edits 3.24, shells 0.35, settings 1.06. It was 97 to 169 ms.
- FirstOpenRender first frame: chat 3.5 ms, sub-agents 2.0 ms (was 59.6), file edits 4.0, shells and settings 1.0.
- ChatScrollbarMetrics: 1503 ns, 0.28x his 5324. It was 3.05x.
- SessionViewLongTranscriptAtTheTail 1.14 ms (was 36.3), ScrolledBack 1.18 ms (was 21.9).
- ProgressedScreenRender: chat 0.48 ms, sub-agents 1.15, file edits 2.55, shells 0.24, settings 0.04. Sub-agents and file edits read 3 to 4% above the first run, inside run-to-run noise.

Two rows grew and stay inside budget:
- LongSessionRender/sub-agents: 2.69 ms, was 1.98. The cards are now built lazily, and at 300 ms the first build of each card falls inside the timed loop.
- SubAgentView (synthetic): 1.53 ms, was 1.01, for the same reason.

Largest remaining cost on sub-agents: `pointer.Overlay` and `look.PlainSurfaceFast`, at 20% and 11% of a frame.
