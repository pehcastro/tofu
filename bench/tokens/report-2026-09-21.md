## What this does not settle

**The 88.4% is a bound, not a clean measurement of the cap alone.** The eleven `*` calls recorded at about 6.3 MB each ran in a working directory that is not this repository, and replaying them here gives 10,289 bytes against a tree of 1,221 files. The drop for those calls mixes the cap with the difference between two trees. The cap's own effect, measured within one tree, is visible on the `*` call replayed today: 1,221 paths matched and 300 returned, 75.4% of the paths dropped, and by the per path average of the capped output, about 41,800 bytes uncapped against 10,289 capped. Every call recorded and replayed in the same tree, which is every call from `turn-18d6f0fb4994d0ac` onward, shows `was bytes` and `now bytes` equal except where the cap, an ignore rule or a deleted directory bit.

**The replay tree moves under the report, and it moved inside this report.** The byte tables ran at 20:07 and `*` matched 1,221. The capped output block four minutes later matched 1,220. The previous report saw 1,055 and warned that a later run would see 1,057. A path count in the third column is a count of this tree on the minute it ran and nothing stronger. No conclusion here turns on one file, but the cap band above does turn on the largest scoped call, which grew by 17 paths in one day, so that band is worth rechecking rather than quoting.

**Five of the 142 calls name a directory that no longer exists and cannot be replayed at all.** Their recorded bytes are kept and counted, so no byte total is affected, but their path counts are unknowable from this tree. A replay bench over a live repository decays this way, and the number to watch is that skip count rather than any single row.

**Which 300 of the 1,220 paths should come back is not measured here and cannot be, because until this cap existed the answer was always all of them.** The free rival for that judgment is the sort order, which is currently the walk order. That is the next ticket.

**`read` at 2,268,556 bytes over 296 calls and `bash` at 2,408,912 over 419 are now within 6.2% of each other**, closer than the 8% of the previous report. Neither is dominated by a handful of huge results the way glob was, so the next saving is a per call one and will be smaller than this one by an order of magnitude.
