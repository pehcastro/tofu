Cost unit: money, list price. A money figure is dollars that left the account behind the credential named above, read from the response of the call it names and never from a rate card. Money and list price do not add. Money left an account. A list price is what a rate card says the call would have cost, and nobody was charged it. An unpriced call spent subscription quota, which carries no price at all.

## The live A/B, not run

Turn against turn: 13 tasks, 3 passes per arm, on a subscription model. On: `browserDriver` goal, and the turn calls `browser_do`. Off: `browserDriver` steps, and the turn's model calls `browser_observe` and `browser_act` step by step. Per run, record success by the task's own check, actions, turn tokens and Jev tokens apart, wall time, and Jev dollars.

Adoption check: Jev keeps the default if its success is within one task of the model arm, its median wall time is at most 0.5x the model arm's, and its turn tokens are at most 0.3x. Otherwise it is written up for him. Verdict: not evaluated, the A/B has not run.

`$hotel` is jev-ultrafast's hotel fixture server and `$fixtures` is fastbrowse's fixture server (`src/fastbrowse/evals/local.py`), which records the POSTs the local tasks are graded on.

```powershell
$model = "claude-sub/claude-opus-5"
$hotel = "http://127.0.0.1:8000"
$fixtures = "http://127.0.0.1:8001"
tofu settings set browser drive
tofu settings set browserOpensTabs 1
foreach ($pass in 1..3) {
  foreach ($arm in "goal", "steps") {
    tofu settings set browserDriver $arm
    tofu run --model $model --dir (New-Item -ItemType Directory -Force "$env:TEMP\tofu-browser-ab\$arm-$pass-hotel").FullName "Open $hotel/fixture.html in a new tab, then: Search Lisbon, choose the Design category, turn on Free cancellation, and open Casa Flora."
    tofu run --model $model --dir (New-Item -ItemType Directory -Force "$env:TEMP\tofu-browser-ab\$arm-$pass-search-price").FullName "Open $fixtures/shop.html in a new tab, then: What is the price of the Blue Kettle?"
    tofu run --model $model --dir (New-Item -ItemType Directory -Force "$env:TEMP\tofu-browser-ab\$arm-$pass-contact-form").FullName "Open $fixtures/contact.html in a new tab, then: Tell support, as Ada Lovelace (ada@example.com), that my kettle arrived broken. Use the damaged item topic."
    tofu run --model $model --dir (New-Item -ItemType Directory -Force "$env:TEMP\tofu-browser-ab\$arm-$pass-contact-needs-confirmation").FullName "Open $fixtures/contact.html in a new tab, then: Tell support, as Ada Lovelace (ada@example.com), that my kettle arrived broken. Use the damaged item topic. Do not submit without asking me."
    tofu run --model $model --dir (New-Item -ItemType Directory -Force "$env:TEMP\tofu-browser-ab\$arm-$pass-table-extract").FullName "Open $fixtures/cities.html in a new tab, then: Get Lyon's population."
    tofu run --model $model --dir (New-Item -ItemType Directory -Force "$env:TEMP\tofu-browser-ab\$arm-$pass-login-wall").FullName "Open $fixtures/account.html in a new tab, then: Show me my recent orders."
    tofu run --model $model --dir (New-Item -ItemType Directory -Force "$env:TEMP\tofu-browser-ab\$arm-$pass-confirm-dialog").FullName "Open $fixtures/drafts.html in a new tab, then: Delete my Holiday post draft."
```
